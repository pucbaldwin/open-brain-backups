Open Brain Backups

A personal backup utility for a self-hosted Open Brain memory system. It is maintained by the GitHub account pucbaldwin for the account owner's own use.

What the app does

The utility uses rclone to encrypt backup archives before copying them to the owner's Google Drive. The owner can retrieve and decrypt those archives to recover the system.

Google Drive access

The app requests the drive.file permission to create, read, update and remove the backup files and folders it creates or that the owner explicitly authorizes for this app. Google sign-in is required before it can access those files.

About this website

This is the public information site for the backup utility. Backups, memory contents and access credentials are stored separately. The site has no sign-in form and does not accept uploads.

Read the privacy policy for details about data handling, storage and revoking access.
