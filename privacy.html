Privacy policy

Open Brain Backups is a personal-use backup utility maintained by pucbaldwin. This policy describes the backup utility and this information website. It does not describe the separate AI applications connected to an Open Brain system.

Data used and purpose

The utility processes backup archives selected by the owner. Archives can contain stored thoughts, system configuration and credentials. It also uses Google authorization tokens and file metadata, such as file names, sizes and modification times, to upload, verify, retain and restore backups.

Google permissions

The utility requests https://www.googleapis.com/auth/drive.file. This permits access to files and folders created by the app or explicitly authorized for it. The requested access is used only for the owner's backup and recovery operations.

Storage and security

Backup archives are encrypted on the owner's equipment before they are uploaded to Google Drive. Google stores the encrypted copies in the owner's account. Local backup copies are stored separately on the owner's equipment. Authorization tokens and the encryption configuration are kept on the devices that perform the backup operations, with access restricted to the owner and system administrators. The recovery password must be kept separately by the owner.

Sharing and other uses

The backup utility does not sell Google user data, use it for advertising or use it to train AI models. Google receives the encrypted backup files and the metadata needed to provide Drive storage. The utility does not intentionally share backup contents with other people or publish them on this website.

Retention and deletion

The owner controls backup retention and can delete local and Google Drive copies. Files removed from Drive may remain in Drive's Trash until it is emptied or Google removes them under its retention rules. Revoking authorization stops future access; it does not automatically erase existing backups.

Revoking access

The owner can remove Open Brain Backups from the Google Account connections page at any time. Backup operations that require Drive access will then need authorization again.

This website and contact

This static website is hosted by GitHub Pages. It has no analytics scripts, advertising, forms or app-managed cookies. GitHub may process request information under its privacy statement.

For questions about this utility or its data handling, use the support email shown on the app's Google consent screen. Do not send backup archives, passwords or authorization tokens in public GitHub issues.
